    If nu is NOT present in the guest (likely — nu is not in smolBSD package set):
    Run the tpm2-tools commands directly via SSH (replicating what tpm-seal-test.nu does):
    ```sh
    ssh studio@10.0.2.42 << 'ENDSSH'
    PASS=smolbsd
    SSH="sshpass -p $PASS ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -p 2241 root@127.0.0.1"

    # Step 1: Create primary key
    $SSH "tpm2_createprimary -T device:/dev/tpm0 -C o -g sha256 -G ecc -c /tmp/primary.ctx"

    # Step 2: Create PCR policy (sha256:0,7)
    $SSH "tpm2_createpolicy -T device:/dev/tpm0 --policy-pcr -l sha256:0,7 -L /tmp/pcr.policy"

    # Step 3: Write secret
    $SSH "echo 'smolbsd-seal-test' > /tmp/secret.txt"

    # Step 4: Create sealed object
    $SSH "tpm2_create -T device:/dev/tpm0 -C /tmp/primary.ctx -i /tmp/secret.txt \
          -u /tmp/seal.pub -r /tmp/seal.priv -L /tmp/pcr.policy \
          -a 'fixedtpm|fixedparent|noda|adminwithpolicy'"

    # Step 5: Load
    $SSH "tpm2_load -T device:/dev/tpm0 -C /tmp/primary.ctx \
          -u /tmp/seal.pub -r /tmp/seal.priv -c /tmp/seal.ctx"

    # Step 6: Unseal
    $SSH "tpm2_unseal -T device:/dev/tpm0 -c /tmp/seal.ctx --auth pcr:sha256:0,7"

    echo "T5 complete"
    ENDSSH
    ```
    Capture the output. If the unseal command prints "smolbsd-seal-test", T5 passes.

    Write TOML result to /tmp/smolbsd-t5-seal-results.toml:
    ```sh

    t        = "T5"
    subject  = "seal/unseal round-trip with PCR 0+7 policy on /dev/tpm0"
    expected = "tpm2_unseal output == 'smolbsd-seal-test'"
    probe    = "tpm2_create + tpm2_load + tpm2_unseal --auth pcr:sha256:0,7"
    evidence = "unsealed output: smolbsd-seal-test (matches)"
    verdict  = "pass"
    EOF
    TOMLEOF
    ```
    Adjust the evidence field to match actual output. If unseal failed, set verdict = "fail".
