  <name>Task 2: Verify image size and write SHA256 manifest</name>
  <files></files>
  <read_first>

  <action>
    On pop4090, verify the built image passes the 512 MiB size check and write
    the SHA256 manifest.

    ```sh
    ssh studio@10.0.2.42 << 'ENDSSH'
    set -e
    IMAGE=/home/studio/smolbsd-ci/smolbsd-amd64-tpm.qcow2

    # 1. Verify image format and actual size
    qemu-img info --output=json "$IMAGE" | python3 -c "
    import json, sys
    info = json.load(sys.stdin)
    actual = info.get('actual-size', info.get('virtual-size', 0))
    limit = 536870912  # 512 MiB
    print(f'actual-size: {actual} bytes ({actual/1048576:.1f} MiB)')
    if actual >= limit:
        print(f'FAIL: {actual} >= {limit} (512 MiB limit)')
        sys.exit(1)
    else:
        print(f'PASS: {actual} < {limit}')
    "

    # 2. Write SHA256 manifest (per D-03: CI cache invalidation)
    sha256sum "$IMAGE" > "${IMAGE}.sha256"
    cat "${IMAGE}.sha256"

    # 3. Also record build metadata alongside the manifest
    cat > /home/studio/smolbsd-ci/BUILD-INFO.txt << 'BUILDINFO'
    KERNCONF=SMOLBSD
    VM_EXTRA_PACKAGES=tpm2-tools
    VMFORMATS=qcow2
    VMSIZE=2g
    BUILDINFO
    date >> /home/studio/smolbsd-ci/BUILD-INFO.txt
    echo "Build complete"
    ENDSSH
    ```

    If qemu-img is not available on pop4090, install it:
    ```sh
    ssh studio@10.0.2.42 "sudo apt-get install -y qemu-utils"
    ```
