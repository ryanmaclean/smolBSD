    SSH to pop4090 (studio@10.0.2.42) and run the following in sequence:

    Step 1: Reset swtpm state (wipes all prior PCR state per Pitfall 4):
    ```sh
    ssh studio@10.0.2.42 "nu /home/studio/smolbsd-repo/bin/swtpm-setup.nu --action reset --state-dir /var/run/smolbsd-tpm 2>&1 || echo RESET_DONE"
    ```
    (If swtpm was not running, reset will start fresh — that is fine.)

    Step 2: Launch QEMU with the smolBSD image in background.
    qemu-smolbsd.nu --tpm will start a new swtpm daemon using the (now-empty)
    state dir, then launch QEMU. Run in background so we can poll SSH:
    ```sh
    ssh studio@10.0.2.42 << 'ENDSSH'
    # Run QEMU in background; redirect output to log
    cd /home/studio/smolbsd-repo
    nohup nu bin/qemu-smolbsd.nu \
      --image /home/studio/smolbsd-ci/smolbsd-amd64-tpm.qcow2 \
      --arch amd64 \
      --tpm \
      --tpm-state /var/run/smolbsd-tpm \
      --hostfwd-ssh 2241 \
      --mem 512M \
      --name smolbsd-tpm-test \
      > /tmp/smolbsd-qemu.log 2>&1 &
    echo "QEMU PID: $!"
    ENDSSH
    ```

    NOTE: The repo must be accessible on pop4090. If not yet cloned, clone it:
    ```sh
    ssh studio@10.0.2.42 "test -d /home/studio/smolbsd-repo || git clone https://github.com/<org>/smolBSD /home/studio/smolbsd-repo"
    ```
    Or use the worktree path if the repo is already checked out elsewhere on pop4090.
    Adjust the path as needed based on what 03-PREFLIGHT-NOTES.md shows.

    Step 3: Poll SSH until the guest responds (timeout 120s for KVM boot):
    ```sh
    ssh studio@10.0.2.42 << 'ENDSSH'
    for i in $(seq 1 120); do
      if sshpass -p smolbsd ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null \
           -o ConnectTimeout=3 -p 2241 root@127.0.0.1 "echo UP" 2>/dev/null; then
        echo "SSH_UP at ${i}s"
        break
      fi
      sleep 1
    done
    ENDSSH
    ```

    If SSH does not respond within 120s:
    - Check /tmp/smolbsd-qemu.log for QEMU errors
    - Check if swtpm socket exists: ssh pop4090 "test -S /var/run/smolbsd-tpm/swtpm.sock && echo SOCK_OK"
    - Common failures: image not found, OVMF.fd path wrong, KVM permission denied
  </action>
