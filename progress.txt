## Codebase Patterns
- Coordinator behavior is centered in `bin/coord-tick.nu`; most user stories touching FSM logic should start there.
- mbox message parsing and TOML extraction conventions live in `bin/mbox-parse.nu`; parser changes must be covered by `tests/mbox-parse-test.nu`.
- HALT semantics are split: per-task markers (`HALT.<task_id>`) and global halt marker (`HALT`) are handled differently by runner and tick scripts.
- Test-first validation should use Nushell test scripts before broader shell wrappers for faster feedback.
- For attestation gating, infer `attestation_required` from the originating request via reply `In-Reply-To` linkage; do not trust only reply-local flags.
- For coordinator-dispatched flows, attestation checks must follow the full `In-Reply-To` chain (reply -> dispatched message -> original request), not just one hop.
